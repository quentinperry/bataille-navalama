# Bataille Navale Lama 🦙 vs Mouton 🐑

Petit site statique avec un mini-jeu de bataille navale : le capitaine **Léo le Lama**
affronte le capitaine **Wooly le Mouton**.

## Jouer

Ouvrez simplement `index.html` dans un navigateur (aucune dépendance, aucun serveur requis).

## Règles

- Grille 10×10, flotte de 5 bateaux (5, 4, 3, 3, 2 cases).
- Placez votre flotte à la main (clic, bouton 🔄 pour orienter) ou aléatoirement (🎲).
- Cliquez sur la grille ennemie pour tirer. Touché = on rejoue, raté = au tour de Wooly.
- Le premier capitaine qui coule toute la flotte adverse gagne.

## Fichiers

- `index.html` — structure de la page
- `style.css` — mise en page et animations
- `game.js` — logique du jeu
